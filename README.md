
# UI-UX-Experiment 3

## Aim
To apply Heuristic Evaluation of an Existing Website or App.

## Problem Statement
Compare and analyze the UX of 2–3 competing shopping applications and incorporate required usability improvements into a redesigned interface.

## Algorithm
1. Select competing e-commerce applications.
2. Evaluate them using Jakob Nielsen’s 10 Usability Heuristics.
3. Identify usability issues and compare their features.
4. Propose improvements based on the evaluation.
5. Design a hybrid shopping application interface.
6. Validate the redesign using A/B testing.

A heuristic evaluation was conducted on Amazon, Flipkart, and Myntra based on product discovery, navigation, product details, and cart management.

### Comparison and Analysis

- **Amazon:** Offers extensive products and detailed information but can feel cluttered.
- **Flipkart:** Provides easy shopping and deals, but promotional content may reduce clarity.
- **Myntra:** Has attractive product presentation but focuses mainly on fashion.

### Proposed Improvements

The redesigned application, **ShopSphere**, combines useful features from the evaluated applications.

- Clean and organized home screen
- Easy category navigation
- Clear product images, ratings, and prices
- Size and quantity selection
- Simple cart management
- Transparent price details
- Consistent navigation and visual design

### Screen Design

1. **Home:** Search bar, sale banner, categories, and trending deals.
2. **Categories:** Product categories and top brands.
3. **Product Details:** Product image, price, rating, size selection, and purchase options.
4. **My Cart:** Selected products, quantity controls, discounts, and checkout.

### A/B Testing

The redesigned interface can be compared with the original application using:

- Product search time
- Add-to-cart success rate
- Checkout completion rate
- User satisfaction

## Result

The ShopSphere redesign improves product discovery, navigation, and cart management through a clean interface, organized categories, and clear pricing. It aims to provide a simple and convenient shopping experience.
